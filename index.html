Daten sichern und laden

Alle Daten liegen nur in diesem Browser. Sichere sie regelmäßig, sonst gehen sie beim Löschen der Browserdaten verloren.

Sichern

Den kopierten Text z. B. in einer Notiz oder Textdatei aufbewahren. „Als Datei speichern“ funktioniert nur, wenn die App direkt als Datei geöffnet ist.

Laden

Gesicherten Text einfügen oder eine gespeicherte Datei wählen. Die aktuellen Daten werden dabei ersetzt.
